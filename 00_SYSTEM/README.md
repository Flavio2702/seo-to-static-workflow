# 00_SYSTEM

Contiene le regole del workflow riutilizzabile: ordine delle fasi, componenti logici, contratti degli artifact, gating e Definition of Done.

Questi file descrivono il sistema. Non sono prompt da copiare negli agenti e non contengono dati cliente.

File operativo aggiunto dallo sprint Design/QA Fast Lane:

- `DESIGN_QA_FAST_LANE_KERNEL.md`: Kernel tecnico riusabile per layout family, home lock, coverage e fallback Classic; non contiene estetica cliente.

I pacchetti sprint cross-session fanno eccezione alla regola sui prompt: sono entry point operativi espliciti e versionati. Per lo sprint Design/QA Fast Lane usare:

- `docs/LIMITI.md`: ordine dei blocchi e prompt copiabili;
- `docs/LIMITI.md`: stato vivente, decisioni, verifiche e prossima azione.
