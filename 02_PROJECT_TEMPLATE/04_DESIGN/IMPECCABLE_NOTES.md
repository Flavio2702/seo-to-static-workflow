# Impeccable notes

## Funzione

Note operative da passare a Impeccable per produrre o rifinire la direzione visuale.

## Input obbligatori

- Bridge locale `PRODUCT.md` nella root cliente: presente / assente
- Bridge locale `DESIGN.md` nella root cliente: presente / assente
- `01_INPUT/PRODUCT.md`: presente / assente
- `03_SEO_GEO/SITE_STRATEGY.md`: presente / assente
- Reference estetiche: presenti / assenti
- File reference in `04_DESIGN/reference_assets/`: presenti / assenti

## Working directory

- Cartella cliente: `projects/<cliente>/`
- Impeccable eseguito da dentro la cartella cliente: si / no
- Uso di `--target projects/<cliente>` dalla root: no

Se la working directory non e dentro `projects/<cliente>/`, bloccare il design e aggiornare `WORKFLOW_STATUS.md`.

## Note per Impeccable

- Non modificare sitemap approvata.
- Non cambiare CTA primaria senza decisione esplicita.
- Non eliminare NAP, segnali locali o trust signals.
- Non trasformare placeholder semantici in lorem ipsum.
- Progettare per HTML statico, CSS/Tailwind-ready e JavaScript vanilla.
- Usare i bridge locali solo come contesto Impeccable; le fonti decisionali restano gli artifact canonici.
- Usare reference visuali solo come input estetico; non usarle per inventare dati, claim o servizi.
