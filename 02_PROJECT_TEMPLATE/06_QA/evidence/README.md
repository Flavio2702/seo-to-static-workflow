# Evidenze QA

Salvare qui screenshot, snapshot, log filtrati o altre prove da conservare per la consegna cliente.

Regole:

- usare nomi file descrittivi e legati al controllo;
- citare ogni evidenza conservata in `06_QA/QA_REPORT.md`;
- produrre ogni evidenza solo dopo il checkpoint contemporaneo previsto e collegarla a fase/ciclo QA; un file nuovo senza checkpoint precedente apre un blocco, va registrato e poi rimosso prima di ripetere il ciclo con prove valide; un checkpoint retroattivo non sana il file originario;
- non dipendere da `output/`, `.playwright-mcp/` o `.impeccable/` alla root della repo workflow;
- non inserire dati sensibili non necessari.
