# images

Immagini del progetto cliente.

Usare foto reali quando disponibili. Evitare immagini pesanti, generiche o non coerenti con l'attivita.

Se il cliente non ha ancora fornito foto, i componenti visivi portanti usano asset visuali di esempio (illustrazioni o SVG locali coerenti con palette e soggetto), registrati come `di esempio, da sostituire con foto reali` nell'Asset inventory dello spec e come lacuna in `01_INPUT/MISSING_INFO.md`. Vietato fabbricare prove specifiche (volti come team reale, recensioni visive, insegne con nomi diversi).
