# Missing info

## Funzione

Elenco di dati mancanti che bloccano o indeboliscono il workflow.

## Bloccanti

- [ ] Identita attivita completa.
- [ ] Offerta principale.
- [ ] CTA primaria.
- [ ] Dati locali minimi.

## Non bloccanti ma utili

- [ ] Foto reali.
- [ ] Recensioni.
- [ ] Competitor.
- [ ] Reference estetiche.
- [ ] Keyword o query note.

## Bloccanti solo per consegna reale

- [ ] Dominio reale confermato.
- [ ] Stato del sito precedente confermato; se esiste, inventario URL vecchie completo.

Queste lacune non bloccano Gate 1. Restano bloccanti per Gate 5 salvo l'eccezione run di test definita in `00_SYSTEM/GATING_RULES.md`.

## Lacune che producono contenuti non pubblicabili

Sottoinsieme delle lacune sopra. Va compilato quando una lacuna rende un contenuto `non pubblicabile`, cioe non rappresentabile nemmeno come placeholder semantico perche la sola descrizione dell'atteso sarebbe gia un'affermazione. Definizione e obblighi in `00_SYSTEM/ARTIFACT_CONTRACTS.md`, sezione `Stati del contenuto`.

| Contenuto | Dove sarebbe comparso | Perche non e neutralizzabile in placeholder | Dato che lo sbloccherebbe |
| --- | --- | --- | --- |
|  |  |  |  |

Finche la riga esiste, il contenuto non entra in HTML ne nei dati strutturati. Si chiude solo con un dato vero e verificabile, mai riformulando il testo.
